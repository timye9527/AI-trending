# AI 2028 地图

一份通俗版的系统性报告：AI 发展到哪一步、为什么 2028 是关键节点、经济与社会会怎么变、从业者怎么办，以及 2026 → 2027 → 2028 的个人行动路线图。中美对照，高中生也能读懂。

- 版本：v1.0（2026 年 10 月）
- 数据截至：2026 年 9 月
- 形式：单个网页 `index.html`，不依赖任何服务器、数据库或构建工具

---

## 一、怎么看这份报告

**方法 1：本地直接打开（最简单，永远可用）**

1. 在 GitHub 仓库页面点绿色 `Code` 按钮 → `Download ZIP`，或者 `git clone`
2. 解压后双击 `index.html`，用浏览器打开即可

**方法 2：变成一个网址（GitHub Pages，免费）**

1. 先把工作分支合并到 `main`（见下文"分支说明"）
2. 仓库页面 → `Settings` → `Pages`
3. `Source` 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，保存
4. 等 1~2 分钟，页面会显示网址，一般是 `https://<你的用户名>.github.io/<仓库名>/`

仓库里的 `.nojekyll` 文件是为了让 GitHub Pages 原样发布网页，不要删除。


## 三、如果出问题了，怎么恢复

这份报告存在 GitHub 上，所以账号、电脑、AI 工具任何一个出问题，内容都不会丢。

| 情况 | 怎么办 |
|---|---|
| Claude / AI 账号不能用了 | 报告不依赖任何 AI 账号。换任何 AI 工具（另一个 Claude 账号、ChatGPT、Cursor 等），把仓库给它，并把下面"四、继续更新的指令"整段发给它即可 |
| 电脑坏了 / 换电脑 | 新电脑上 `git clone https://github.com/timye9527/AI-trending.git`，或在网页上下载 ZIP |
| 本地改乱了 | `git checkout -- index.html` 撤销未提交的修改；或 `git log` 找到之前的版本，`git checkout <提交号> -- index.html` 恢复 |
| 想看历史版本 | GitHub 仓库页面 → `Commits`，每一次更新都有记录 |
| 工作分支找不到 | 本次工作在分支 `claude/ai-economy-impact-report-0s3pc1`。在仓库页面左上角分支下拉框里选择它；或 `git fetch origin && git checkout claude/ai-economy-impact-report-0s3pc1` |
| GitHub 账号也出问题 | 建议现在就额外备份：下载 ZIP 存到网盘一份。整个报告只有一个 HTML 文件，非常容易备份 |
| 网页打开后字体不一样 | 正常。字体从 Google Fonts 加载，网络不通时会自动换成系统字体，内容不受影响 |

```
l4 从业者怎么办、l5 路线图）和附录信号表。

这次请帮我：
1. 搜索最新数据，更新附录"信号表"的"当前值"一列，以及正文中对应的数字
   （METR 时间跨度、美国应届生失业率、中国青年失业率、四大云厂商资本开支、
   Anthropic 经济指数、推理价格、中国"人工智能+"进展）。
2. 如果有新的前沿模型时间跨度数据，追加到 index.html 底部的 metr 数组。

5. 保持原有的通俗风格（高中生能看懂）、中美对照和"说真话"的基调。
```

### 建议的更新节奏

- **每季度**：更新附录信号表（约 30 分钟）
- **每半年**：复盘第五层的情景判断，调整个人行动
- **每年年底**：大版本更新（v2.0 = 2027 版），重写第二层的推演
